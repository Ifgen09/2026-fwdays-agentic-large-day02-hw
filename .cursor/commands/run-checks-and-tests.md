# Run checks and tests

Допомога з локальною перевіркою після змін у цьому репозиторії (корінь монорепо, Yarn).

## Скрипти з кореневого `package.json`

| Задача | Команда |
|--------|---------|
| TypeScript | `yarn test:typecheck` |
| ESLint | `yarn test:code` |
| Prettier (перевірка) | `yarn test:other` |
| Vitest (тести) | `yarn test` або `yarn test:app` |
| Як у CI «all» | `yarn test:all` |

Повна збірка застосунку: `yarn build`. Пакети бібліотеки: `yarn build:packages` (якщо змінювали `packages/*`).

## Що зробити

1. За описом змін користувача або з контексту PR визнач, **які перевірки релевантні** (типи, лінт, тести, збірка).
2. Назви **точні команди** з таблиці вище; не підміняй `yarn` на `npm`/`pnpm` — у проєкті Yarn Classic.
3. Якщо користувач надіслав лог помилки CI — **зістав** її з відповідним скриптом і поясни, що виправити в коді або конфігурації.

## Очікуваний результат

- Одна або кілька команд для терміналу в корені репо.
- Коротко: що означає успішний прогін для його змін.

Додатковий контекст після команди (файл, пакет, текст помилки) враховуй у відповіді.
