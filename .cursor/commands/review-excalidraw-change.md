# Review Excalidraw change

Ревʼю змін у монорепо Excalidraw (Yarn 1 workspaces: `packages/*`, `excalidraw-app`, `examples/*`).

## Контекст

- Деталі стеку та команд: `AGENTS.md` у корені.
- Захищені зони (змінювати лише з повною обережністю): `packages/excalidraw/scene/Renderer.ts`, `data/restore.ts`, `actions/manager.tsx`, `types.ts` — згідно з правилами проєкту.

## Що зробити

1. Коротко опиши **що змінилось**: які файли, яка поведінка для користувача або API.
2. Перевір узгодженість з конвенціями:
   - React: лише функції та hooks; `type ComponentNameProps`; **named exports**.
   - TypeScript: strict; без `any` і без `@ts-ignore`; типи через `import type`.
   - Стилі: CSS modules для компонентів, де це прийнято в репо.
3. Перевір **межі пакетів**: імпорти з `@excalidraw/*` та шари `packages/` vs `excalidraw-app` не повинні порушувати архітектуру.
4. Якщо змінювався публічний API бібліотеки — чи оновлені експорти та типи.

## Вихід

- **Блокери** (якщо є) — що треба виправити перед мерджем.
- **Рекомендації** — покращення без обовʼязкового блокування.
- **Ризик**: низький / середній / високий (регресії, сумісність формату файлів, колаб).

Якщо після команди вказано шлях, файл або тему — зосередь ревʼю на цьому.
